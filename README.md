## Getting Started

### Prerequisites

- Ruby (for build utilities)
- Node.js (for JavaScript dependencies, if applicable)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/reggieterry/reggieterry.github.io.git
   cd reggieterry.github.io
   ```

2. Install dependencies (if applicable):
   ```bash
   npm install
   ```

3. Build the project:
   ```bash
   make build
   ```

4. Serve locally:
   ```bash
   npm start
   ```
